## 🚀 Featured Work

### 🤖 AI Agent Workspace

Exploring a visual environment where multiple AI agents can work together as a software engineering team.

The concept includes:

```text
                  ┌───────────────┐
                  │   Main Agent  │
                  │    Planner    │
                  └───────┬───────┘
                          │
              ┌───────────┼───────────┐
              ▼           ▼           ▼
         Developer       QA        Research
              │           │           │
              └───────────┼───────────┘
                          ▼
                     Final Result
```

The goal is to move beyond:

**"AI generates code."**

toward:

**"AI engineers a solution."**
